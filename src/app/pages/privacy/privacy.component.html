Privacy & Cookie Policy

Last Update: June 2026

1. Project Information (Disclaimer)

ValApp is an amateur, non-commercial project, developed exclusively for personal study purposes and as an element of the creator's professional portfolio. This site is not affiliated, associated, authorized, endorsed, or in any way officially connected with Riot Games, Inc. or any of its subsidiaries or affiliates.

2. Data Source and Third-Party APIs

This application **does not use the official Riot Games API** and does not have access to credentials or private data of game accounts.

All game statistics, match information, agent details, and game data shown in the dashboard are retrieved through **public APIs provided by third parties** (e.g., external trackers and public data aggregators). Only data set as "public" by the users themselves within the game is processed.

3. Types of Data Processed

The application adopts an approach focused on maximum data minimization:

  • Game Data: Riot ID and Tagline are used temporarily only to make the HTTP request to third-party API services and to display the rank and matches on screen.
  • Personal Data: No tracking of the user's real identity is performed. No names, email addresses, IP addresses in a persistent manner, or sensitive data are requested or stored.

4. Cookie Policy

This site uses only **technical cookies** and local storage (such as the browser's localStorage). These tools are used solely to ensure the correct functioning of the application, such as remembering the user's login session or saving interface preferences.

No profiling cookies, advertising cookies, or third-party tracking tools (such as Google Analytics or Meta Pixel) are used.

5. Contacts and Requests

Being a client-side application hosted on a public repository, no data is stored on proprietary servers. For any questions about the code or the functioning of the app, you can directly consult the project's GitHub repository.
